# วิธีเพิ่ม lineup (ทำบนคอม)

## 1. เก็บในเกม

1. เข้า Custom Game แมพนั้น เปิดตัวเลือกให้ใช้สกิลได้ไม่จำกัด
2. หาจุดยืน + จุดเล็งที่ molly ไปตกตรงที่ต้องการ ลองซ้ำ 3 ครั้งให้ชัวร์
3. แคปรูป **จุดยืน** (เห็นสิ่งรอบตัว) และ **จุดเล็ง** (ครอสแฮร์อยู่ตรงไหน) — ใช้ Win + Shift + S แล้ว Ctrl+V ในเว็บได้เลย
4. อัดคลิปสั้นตอนปา 5–10 วินาที (Win + Alt + R หรือ instant replay ของการ์ดจอ)
5. ครอปชื่อในเกม / Riot ID ออก (repo เป็น public)

## 2. กรอกบนเว็บ

1. รันเว็บบนเครื่อง (`python -m http.server 8000`) หรือเปิดเว็บจริงก็ได้
2. เลือกแมพ → **+ เพิ่ม**
3. แตะแมพครั้งที่ 1 = จุดยืน, ครั้งที่ 2 = จุดที่สกิลตก
   - smoke ที่วางจากแมพ: กด **ไม่มีจุดยืน** แล้วแตะแค่จุดวาง
4. แตะไอคอนเลือก **แมพ / เอเจนต์ / สกิล** แล้วเลือกฝั่ง ไซต์ ประเภท
   - ชื่อ lineup จะตั้งให้อัตโนมัติ เช่น `Incendiary B · Post-plant` (พิมพ์ทับได้ กด ↺ เพื่อกลับเป็นอัตโนมัติ)
5. เลือก **การปา** (ปาปกติ / กระโดดแล้วปา / พิมพ์เอง) — จะขึ้นตัวใหญ่บนรูปจุดเล็ง
6. ใส่ **รูปจุดยืน / จุดเล็ง**: แตะช่อง เลือกไฟล์ · หรือแคปจอแล้วกด **Ctrl+V** · หรือลากไฟล์มาวาง
   - เว็บย่อรูปเป็น WebP กว้าง 1280px ให้เอง ไม่ต้องใช้ ffmpeg
   - กด **✎ ไฮไลต์** เพื่อวาดวงกลม / ลูกศร / ปากกา (เลือกสีได้, ย้อนได้, แก้ซ้ำได้ภายหลัง)
7. กรอกวิธีทำ แล้วบันทึก (เก็บในเบราว์เซอร์ก่อน รวมรูป จะมีป้าย "ยังไม่ export")

## 3. ส่งขึ้น GitHub

1. ⋯ → **ส่งออก** (หรือแตะป้ายสีเหลือง)
   - ถ้ามีรูปใหม่ จะได้ `lineups-export.zip` → แตกไฟล์ลงโฟลเดอร์ repo ให้ทับของเดิม
     (ข้างในมี `data/lineups.json` และ `media/<แมพ>/...webp`)
   - ถ้าไม่มีรูปใหม่ จะได้ `lineups.json` → เอาไปแทน `data/lineups.json`
2. ```bash
   git add data media
   git commit -m "Add Brimstone B molly on Ascent"
   git push
   ```
3. รอ 1–2 นาที มือถือจะเห็น ป้าย "ยังไม่ export" และรูปที่เก็บในเบราว์เซอร์จะถูกล้างเองเมื่อเว็บมีไฟล์นั้นแล้ว

### ไม่ใช้ git: อัปโหลดผ่านเว็บ GitHub

1. แตกไฟล์ `lineups-export.zip` จะได้โฟลเดอร์ `data` และ `media`
2. เปิด https://github.com/Cinnammonmio/lineup-notebook → **Add file → Upload files**
3. ลากโฟลเดอร์ `data` และ `media` (ทั้งโฟลเดอร์) มาวางในหน้านั้น
   - ถ้า export ได้แค่ `lineups.json` ให้สร้างโฟลเดอร์ `data` แล้วใส่ไฟล์ไว้ข้างใน ก่อนลากมาวาง
4. ล่างสุดกด **Commit changes** (ให้ commit เข้า `main`)
5. รอ 1–2 นาที แล้วรีเฟรชเว็บบนมือถือ

คลิปยังต้องย่อเองด้วยคำสั่งใน [tools/compress.md](../tools/compress.md) แล้วใส่ path ในช่อง "คลิป / รูปอื่น ๆ"
