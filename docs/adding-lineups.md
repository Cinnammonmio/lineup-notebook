# วิธีเพิ่ม lineup (ทำบนคอม)

## 1. เก็บในเกม

1. เข้า Custom Game แมพนั้น เปิดตัวเลือกให้ใช้สกิลได้ไม่จำกัด
2. หาจุดยืน + จุดเล็งที่ molly ไปตกตรงที่ต้องการ ลองซ้ำ 3 ครั้งให้ชัวร์
3. แคปรูป **จุดยืน** (เห็นสิ่งรอบตัว) และ **จุดเล็ง** (ครอสแฮร์อยู่ตรงไหน)
4. อัดคลิปสั้นตอนปา 5–10 วินาที (Win + Alt + R หรือ instant replay ของการ์ดจอ)
5. ครอปชื่อในเกม / Riot ID ออก (repo เป็น public)

## 2. ย่อไฟล์

ใช้คำสั่งใน [tools/compress.md](../tools/compress.md) แล้ววางไฟล์ใน `media/<แมพ ตัวเล็ก>/`
ตั้งชื่อ: `<เอเจนต์>-<ไซต์>-<สกิล>-<ชื่อสั้น>-<stand|aim>.webp` เช่น `brim-a-molly-default-stand.webp`

## 3. กรอกบนเว็บ

1. รันเว็บบนเครื่อง (`python -m http.server 8000`) หรือเปิดเว็บจริงก็ได้
2. เลือกแมพ → **+ เพิ่ม**
3. แตะแมพครั้งที่ 1 = จุดยืน, ครั้งที่ 2 = จุดที่สกิลตก
   - smoke ที่วางจากแมพ: กด **ไม่มีจุดยืน** แล้วแตะแค่จุดวาง
4. กรอกชื่อ, เอเจนต์, สกิล, ฝั่ง, ไซต์, ประเภท, วิธีทำ
5. ช่องรูป/คลิป ใส่ path บรรทัดละอัน เช่น
   ```
   media/ascent/brim-a-molly-default-stand.webp | จุดยืน
   media/ascent/brim-a-molly-default-aim.webp | จุดเล็ง
   media/ascent/brim-a-molly-default.mp4 | คลิป
   ```
6. บันทึก (ตอนนี้เก็บแค่ในเบราว์เซอร์ จะมีป้าย "ยังไม่ export")

## 4. ส่งขึ้น GitHub

1. ⋯ → **ส่งออก lineups.json** (หรือแตะป้ายสีเหลือง)
2. เอาไฟล์ที่ดาวน์โหลดไปแทน `data/lineups.json`
3. ```bash
   git add data media
   git commit -m "Add Brimstone A molly on Ascent"
   git push
   ```
4. รอ 1–2 นาที มือถือจะเห็น และป้าย "ยังไม่ export" บนคอมจะหายเอง
